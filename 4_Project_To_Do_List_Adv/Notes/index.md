# index.html Notes

This file defines the to-do list page structure.

- Sets the document language and basic page metadata.
- Loads `styles.css` for styling.
- Loads `script.js` with `defer` so the DOM is ready before the script runs.
- Displays a container with:
  - a label for the task input,
  - a form with a text input and submit button,
  - an empty unordered list that will hold the tasks.
